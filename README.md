# My Bayt Almaal — appen till telefonen

Det här projektet innehåller **bara den färdiga appfilen** för Android.
Ingen källkod, ingen data.

Appen är ett skal som öppnar
[my-bayt-almaal.mjxmsl.workers.dev](https://my-bayt-almaal.mjxmsl.workers.dev)
i ett appfönster. Den kräver internet och inloggning — utan konto visar den
ingenting.

## Varför projektet är öppet

Appen hämtas och uppdateras med [Obtainium](https://github.com/ImranR98/Obtainium),
som behöver kunna läsa nedladdningarna utan inloggning. Källkoden ligger kvar i
ett privat projekt; bara den byggda filen publiceras här.

## Installera

Lägg till den här adressen i Obtainium:

```
https://github.com/maal9850/my-bayt-almaal-app
```

Appen är signerad med en egen nyckel. Byter signaturen går appen inte att
uppdatera ovanpå den installerade — då är det inte samma app.
